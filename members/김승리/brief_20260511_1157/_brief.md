## 프로젝트
- **타입:** 앱/서비스 (PWA)
- **스타일:** warm_editorial
- **목적:** 나무십자가교회 성도들이 산발적인 정보를 헤매지 않고, 경건생활과 교회 일상에 필요한 모든 정보를 한 곳에서 편리하게 확인하고 소통할 수 있도록 돕는 것
- **아이디어:** 나무십자가교회 성도들의 경건생활과 일상적인 교회 생활을 돕기 위한 전용 앱. 설교 다시듣기(영상, 요약 이미지), 기도제목 공유, 말씀연구(DBS) 공유, 게시판, 커피주문, 물품주문(재고 확인), 교회 달력 등의 콘텐츠를 제공

## 브랜드 코어 (노바 확정)

### 슬로건
> **"모이면 됩니다."**

### 브랜드 코어
흩어진 신앙 생활을 조용히, 단단하게 모아주는 공동체의 중심.

### BEAT
| | 내용 |
|---|---|
| **B — Business Definition** | 성도들의 경건생활과 교회 일상이 한 곳에서 이어지도록, 공동체의 연결을 붙잡는다 |
| **E — Experiential Problem** | 설교는 유튜브, 공지는 단톡방, 기도제목은 밴드, 주문은 구글폼 — 채널 파편화로 인한 나눔 단절과 "어디 있더라"의 반복 피로 |
| **A — Actual Solution** | 교회 생활 전체(설교·기도·말씀·소통·주문·일정)를 성도 전용 앱 하나로 통합. 올드하거나 복잡하지 않게, 따뜻하고 깔끔하게 |
| **T — Thrilling Concept** | "모이면 됩니다." / 컨셉 워드: 위드(WITH) — 히브리서 10:25 모임의 언어에서 착안 |

## 기술 스택 (아틀라스 확정)

| 항목 | 선택값 | 이유 |
|------|--------|------|
| 프론트엔드 | Next.js 14 (App Router) | tomob 표준. SSR 설교 목록 대응. 풀스택 단일 레포 |
| 백엔드/API | Next.js Route Handlers + Supabase Client | 별도 서버 불필요. MVP 속도 우선 |
| 데이터베이스 | Supabase PostgreSQL | RLS 권한 제어. 실시간 구독 기본 제공 |
| 인증 | Supabase Auth (이메일+비밀번호) | 관리자가 계정 직접 생성. 내부 앱 통제 용이 |
| 미디어 | YouTube 임베드 | 영상 직접 업로드 시 비용 급증 → YouTube 채널 연동 |
| 배포 | Vercel | tomob 표준. 무료 티어 MVP 충분 |
| 알림 | Supabase Realtime (Phase 2: FCM) | MVP는 인앱 알림만 |
| 앱 형태 | PWA | 앱스토어 심사 없음. 홈화면 추가로 앱처럼 사용 |

## ERD (핵심 테이블)

**users** — id(uuid) / name / role('member'|'admin') / created_at
**sermons** — id / title / preacher / youtube_url / scripture / sermon_date
**prayer_requests** — id / user_id / title / content / is_public / created_at
**posts** — id / user_id / category('board'|'dbs'|'notice') / title / content / created_at
**orders** — id / user_id / type('coffee'|'item') / items(jsonb) / status('pending'|'done') / created_at
