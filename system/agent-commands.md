# Survey Corps 명령어 시스템

채팅창에서 `/` 로 시작하는 명령어를 사용할 수 있습니다.

| 명령어 | 설명 |
|--------|------|
| `/set` | tomob-seed 브리프 템플릿 로드. 기획서 작성 전 반드시 실행. |
| `/start` | 새 기획서 세션 시작. 현재 대화 초기화. |
| `/brief` | 지금까지 대화한 내용으로 기획서 즉시 생성 요청. |
| `/submit` | 완성된 기획서를 GitHub에 제출. |
| `/help` | 이 명령어 목록 출력. |

## 권장 순서

```
/set → 대화 시작 → /brief (필요시) → /submit
```
